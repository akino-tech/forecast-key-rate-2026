# Данные и воспроизведение

Источник: Bank of England, *A Millennium of Macroeconomic Data for the UK*, книга v3.1 по каталогу ESCoE. Скачана 11.11.2026. В полученной книге годовые ряды заканчиваются 2016 годом. Исторические значения реконструированы; их точность и определения неоднородны.

- `raw/boe-headline-extract.json`: значения без аналитических преобразований, 237 строк, 1780–2016. Колонки и SHA-256 полной исходной книги — в `raw/metadata.json`.
- `processed/series.csv`: уровни, ВВП на душу населения, тренды/остатки и скользящие средние.
- `processed/turning-points.csv`: все результаты оконного сопоставления, включая крайние значения.
- `processed/summary.json`: машинно-читаемые результаты и экстремумы после 1920 года.

В корне репозитория: `python scripts/analyse.py`. Зависимости: Python 3, numpy, pandas. Обработка локальная, сетевых запросов скрипт не делает. Краевые пропуски скользящего среднего ожидаемы; исходных пропусков в выбранной выборке нет. Первоначальный скрипт выполняет описательное сопоставление. Спектральная проверка добавлена отдельным скриптом ниже; причинность и прогноз 2026 года из этих рядов не оцениваются.

Для проверки извлечения скачать оригинальную книгу по URL из метаданных, сверить SHA-256 и лист `A1. Headline series`, столбцы A/B/Y/AO/AR. Полная книга и полный текст Кондратьева в репозиторий не включены; доступны по ссылкам. Другие источники в таблице чтения предлагаются для будущего расширения, не выдаются за использованные данные.


## Расширение 12.11.2026

- `python scripts/deeper_analysis.py`: рост по периодам; 90 результатов чувствительности; спектры логарифмических уровней и роста; по 5 000 симуляций AR(1) с фиксированным seed. Выходы: `growth-regimes.csv`, `robustness-turns.csv`, `spectral-summary.csv`, `spectral-density.csv`, `spectral-null.csv`.
- `python scripts/company_forecast.py`: коэффициенты NVIDIA из `raw/nvidia-financials.json`, стресс-сценарии, условная модель полной стоимости владения, сценарии ставки и байесовская чувствительность. Выходы: `nvidia-ratios.csv`, `nvidia-stress.csv`, `tco-scenarios.csv`, `rate-scenarios.csv`, `forecast-sensitivity.csv`, `company-model-summary.json`.

Финансовые значения — опубликованные GAAP-данные; все параметры модели клиента, сценарные веса и отношения правдоподобия — явно обозначенные предположения. Статистические ограничения подробно раскрыты в исследовательском приложении. Установка зависимостей: `python -m pip install -r requirements.txt`.
